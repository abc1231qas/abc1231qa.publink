# 05 — 設計

## 風格一句話

**東方禪意極簡（Zen Minimalism）**：大量留白、低飽和度、宋體字、水墨圓圈作視覺核心。  
從「現代科技風」改造成「人文知性品牌」，目標讓人**放慢閱讀速度**。

## 配色（墨與金）

| 用途 | 色票 | 備註 |
|------|------|------|
| 背景 | `#F7F7F5` | 米白，模擬紙張，避免純白刺眼 |
| 主筆觸 / 深色文字 | `#2C2C2C` | 墨黑 |
| 標題文字 | `#333333` | 略深於內文 |
| 內文文字 | `#595959` | 中灰，長閱讀不疲勞 |
| 強調 / hover | `#C5A065` | 霧金（Antique Gold），用在分隔線、圓圈、互動狀態 |
| 淡金背景 | `rgba(197,160,101,0.15)` | hover 底色 |

> 規則：純白與飽和色都不用。整站只有「米白 / 墨黑 / 霧金」三軸，加上灰階文字。

## 字型

- **中文**：Noto Serif TC（思源宋體），備用 PMingLiU
- **英文**：Times New Roman / Garamond / Baskerville
- **不用黑體**：會破壞禪意

層級：

- h1 — `2.8rem` / `font-weight: 300` / `letter-spacing: 0.15em`
- 副標 — `1rem` / `letter-spacing: 0.3em`
- 內文 — `1.05rem` / `line-height: 2`

## 視覺核心：水墨圓圈（Enso）

不完整的圓 + 微微旋轉，中心放金色光暈。CSS 做法是 `border-radius: 50%` 加上把上、右兩條 border 設成 `transparent`，再 `transform: rotate(-15deg)`。手繪感不靠圖片，純 CSS。

## 版面

- 居中對稱佈局，`max-width: 680px`
- 留白佔比 **55%**
- 元素間距 60–100px
- 內文區塊最大寬 480px（控制每行字數）

## 動畫

- 元素**漸進式淡入**（依序，不是同時）
- 過渡曲線：`cubic-bezier(0.4, 0, 0.2, 1)`
- 沒有彈跳、沒有 parallax、沒有 hover 放大；一切克制

## 取捨記錄

| 取 | 捨 | 為什麼 |
|----|----|--------|
| 米白背景 | 純白 | 純白螢幕傷眼，米白接近紙張 |
| 宋體 | 黑體 | 宋體有筆鋒、人文感強 |
| 不完整圓 | 完整圓 / logo | 禪宗「圓相」就是不完整 |
| 細邊框按鈕 | 填色按鈕 | 填色太搶眼，細邊框配合留白 |
| 漸進淡入 | 同時出現 / 滑入 | 速度感破壞靜謐 |
| 霧金一色 | 多彩強調色 | 多色違背低飽和原則 |
